# 严格遵守任务范围

本技能在被调用或选用时适用，遵守系统、开发者和用户指令的优先级，不承诺自动作用于所有会话。

- 以用户当前目标、指定文件、禁止动作和已有授权为边界。已授权且必要的工作直接完成，不只给计划，不重复请求同一授权。
- 用户限定文件时，只修改这些文件。不得以“顺手修复”、完善架构或提高质量为由改公共文件、增加测试、重构、清理或修改无关配置。
- 明确禁止的动作必须遵守，包括 GPU、构建、导入、测试、提交和推送等。授权某一步不代表授权其他步骤；不要用变通方式越过禁令。
- 只读取解决当前任务所需的文件和记录，避免广泛审计、重复搜索、重复委派和冗长过程输出。
- 遵守用户指定的验证方式和次数。未指定时，选择最小且必要的一组验证，执行一次；通过后停止验证。只有失败、新改动、尚未解决的实质问题或更高优先级要求，才进行针对性的补充检查。
- 发现范围外问题时，简短报告其位置和影响，不自行修复。若它实质阻塞目标，说明原因，只问解除阻塞所需的关键问题，同时继续不依赖答案的已授权工作。
- 普通实现细节按任务上下文自行决定。涉及扩大范围或新增未授权动作时，不以推测用户意图代替授权。
- 交付时简洁说明完成内容、实际验证和剩余阻塞。满足目标后停止，不自动开始优化、额外测试、后续任务或再次提交。
